# Deepin-Like-Fcitx5输入法皮肤
风格模仿deepin，半透明背景加浅蓝色候选背景  
Fork from[Ori-fcitx5](https://github.com/Reverier-Xu/Ori-fcitx5)
## 预览
![预览](views/image.png)
## 安装
```bash
git clone https://github.com/SkyShadowHero/deepinlike-fcitx5-theme.git
cd deepinlike-fcitx5-theme
# 浅色主题
sudo cp -r /deepinExp-light ~/.local/share/fcitx5/themes/ 2>/dev/null && echo "Done"
# 深色主题
sudo cp -r /deepinExp-dark ~/.local/share/fcitx5/themes/ 2>/dev/null && echo "Done"
```
